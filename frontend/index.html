💡 Petunjuk Cara Menghubungkan Banyak Profil Chrome (Multi-Flow):

  1. Buka browser Google Chrome dengan Profile 1, Profile 2, Profile 3, dst.
  2. Di setiap profil, buka chrome://extensions dan aktifkan Developer mode.
  3. Klik Load unpacked lalu pilih folder: E:\AUTO KLIK\Sinematica\engine\chrome-extension
  4. Buka tab flow.google.com (atau labs.google/fx/tools/flow) di setiap profil dan pastikan akun Google sudah Login.
  5. Setelah update extension, klik Reload ⟳ pada Sinematica Flow Agent di chrome://extensions, lalu refresh tab Flow. Extension akan mencoba membaca ulang sesi; jika status masih FLOW_LOGIN_REQUIRED, pastikan Flow sudah login di profil Chrome yang sama.
  6. Extension akan otomatis terhubung ke Sinematica Dashboard ini!

⚡ Ide Viral yang Nyambung ke Produk

SIAPA + NGAPAIN + DI MANA → momen butuh produk → hook 3 detik → satu emosi utama.

Checklist konten yang layak dites
Hook: langsung ke masalah dalam 3 detik, tanpa pembuka formal. Retention: satu video satu pesan, aksi mudah dibaca. Emotion: pilih satu respons utama. Conversion: produk hadir tepat saat dibutuhkan dan manfaat dibuktikan, bukan ditempel. Iteration: buat banyak variasi SIAPA/AKSI/LOKASI lalu ukur hasil tes ombak pertama.
